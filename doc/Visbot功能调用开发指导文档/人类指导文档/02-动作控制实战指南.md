# 02-动作控制实战指南：走动、挥手、扭头、表情

> 本篇是**实战手册**：每个动作给出「最小代码 + 已验证参数 + 坑」。API 完整签名见 `AI指导规范文档/`。
> 所有代码默认已执行 `Robot.initialize(context)`（见快速上手 §5）。

---

## 0. 三个全局概念（先读，否则会踩坑）

1. **异步模型**：所有动作调用返回 `Promise`，不会阻塞主线程。动作是否"已完成"要用 `.done()/.fail()` 回调，或同步等待用 `.get()`（阻塞调用线程，勿在主线程用）。
2. **竞争会话**：同一硬件（比如 head 舵机）同一时刻只允许一个应用控制。你自己应用内两个操作同时抢同一舵机也会互斥，**串行执行或先 release**。
3. **参数都是设备相关的**：下面标注 ✅ 的参数是本机**真机实测通过**的值；未标注的要先 `getDeviceList()` 枚举。

## 1. 扭头（head 舵机）

### 最小代码

```java
ServoController servo = Robot.globalContext().getSystemService("servo");

// 绝对角度：头转到 +20°（右看）
servo.rotate(new RotationOption.Builder("head")
        .setAngle(20f)          // ✅ 实测安全范围 [-23, 25]，超出可能卡机械
        .setAngleAbsolute(true) // 绝对角度（默认 true）
        .setSpeed(50)           // ✅ 15/50/80 均实测可用
        .build());

// 相对角度：在当前基础上再转 -10°
servo.rotate(new RotationOption.Builder("head")
        .setAngle(-10f)
        .setAngleAbsolute(false)  // 相对模式
        .setSpeed(50)
        .build());

// 按持续时间转（不指定角度，转满 duration 毫秒）
servo.rotate(new RotationOption.Builder("head")
        .setDuration(1500)
        .setSpeed(30)
        .build());
```

### 常用场景

```java
// 摇头（左右看）——两段动作串行
servo.rotateSerially(Arrays.asList(
    new RotationOption.Builder("head").setAngle(-23f).setSpeed(80).build(),
    new RotationOption.Builder("head").setAngle(23f).setSpeed(80).build(),
    new RotationOption.Builder("head").setAngle(0f).setSpeed(80).build()
));

// 查询当前角度 / 是否在转 / 释放舵机
float angle = servo.getAngle("head");
boolean rotating = servo.isRotating("head");
servo.release("head");        // 释放后舵机松劲，可被其他应用/手动转动
```

### 坑

- 角度超范围：命令可能被接受但舵机卡死发热。**先用 ±20 以内试**。
- 两个 `rotate` 同时发：后者抢占前者（取决于服务端策略）。想排队用 `rotateSerially`。

## 2. 走路（Locomotion：轮子/底盘）

### 最小代码

```java
LocomotionController loco = Robot.globalContext().getSystemService("locomotion");

// 直行：速度 0.3（✅ 实测值），持续 2 秒后自动停
loco.locomote(new LocomotionOption.Builder()
        .setMovingSpeed(0.3f)
        .setDuration(2000)
        .build());

// 持续前进（duration=0 表示一直走，直到下一条命令）
loco.locomote(new LocomotionOption.Builder()
        .setMovingSpeed(0.3f)
        .setDuration(0)
        .build());

// 后退：负速度
loco.locomote(new LocomotionOption.Builder()
        .setMovingSpeed(-0.3f)
        .setDuration(2000)
        .build());
```

### 转向

```java
// 原地左转 90°：转向速度 30（✅ 实测，单位度/秒），持续 3 秒
loco.locomote(new LocomotionOption.Builder()
        .setTurningSpeed(30f)
        .setDuration(3000)
        .build());

// 按角度转：转 45°
loco.locomote(new LocomotionOption.Builder()
        .setTurningSpeed(30f)
        .setTurningAngle(45f)
        .build());

// 转向轴（三选一）：
//   TURNING_AXIS_CENTER(0) 原地转（默认）
//   TURNING_AXIS_LEFT(-1)  以左轮为轴转
//   TURNING_AXIS_RIGHT(1)  以右轮为轴转
loco.locomote(new LocomotionOption.Builder()
        .setTurningSpeed(30f)
        .setTurningAngle(90f)
        .setTurningAxis(LocomotionOption.TURNING_AXIS_RIGHT)
        .build());

// 紧急停止
loco.locomote(new LocomotionOption.Builder()
        .setEmergency(true)
        .build());
```

### 组合：走弧线 / 边转边走

```java
// 同时设移动速度和转向速度 → 弧线
loco.locomote(new LocomotionOption.Builder()
        .setMovingSpeed(0.2f)
        .setTurningSpeed(15f)   // 右转弧线（负值 = 左弧）
        .setDuration(3000)
        .build());
```

### 路径巡航（多段串行）

```java
// 前进 2 秒 → 右转 90° → 前进 2 秒 → 停
loco.locomoteSerially(Arrays.asList(
    new LocomotionOption.Builder().setMovingSpeed(0.3f).setDuration(2000).build(),
    new LocomotionOption.Builder().setTurningSpeed(30f).setTurningAngle(90f).build(),
    new LocomotionOption.Builder().setMovingSpeed(0.3f).setDuration(2000).build()
));
```

### 坑

- **正负号约定**：负移动速度 = 后退；负转向速度 = 右转（实测确认）。方向反了先想符号。
- `duration=0` 是**持续运动**，不是"不动"。忘发停止命令机器人会一直走。
- 走路过程中发 `locomote` 新命令会**中断**当前运动（除非用 serially）。

## 3. 挥手（手臂舵机组合）

> Visbot 的手臂由舵机驱动。"挥手" = 手臂舵机来回摆。**手臂舵机 ID 必须先枚举**：`servo.getDeviceList()`（本机是 head 这类 ID；有手臂扩展部件的机型会有 arm_left/arm_right）。

### 最小代码

```java
ServoController servo = Robot.globalContext().getSystemService("servo");

// 单臂挥手 3 次（每次“抬起→放下”）
// 注意：Promise 没有 await()，同步等待用 get()（会阻塞调用线程，勿在主线程用）
// 推荐用 rotateSerially 串行执行（见下一段写法）
String armId = "arm_left";   // 以 getDeviceList() 实际返回为准
for (int i = 0; i < 3; i++) {
    servo.rotate(new RotationOption.Builder(armId)
            .setAngle(-60f).setSpeed(80).build()).get();   // 阻塞等待完成
    servo.rotate(new RotationOption.Builder(armId)
            .setAngle(20f).setSpeed(80).build()).get();
}
```

### 更稳的写法（串行 + 回调链）

```java
List<RotationOption> wave = new ArrayList<>();
for (int i = 0; i < 3; i++) {
    wave.add(new RotationOption.Builder(armId).setAngle(-60f).setSpeed(80).build());
    wave.add(new RotationOption.Builder(armId).setAngle(20f).setSpeed(80).build());
}
servo.rotateSerially(wave)
    .done(v -> Log.i("Wave", "挥手完成"));
```

### 坑

- 手臂可能有**机械限位**，先小角度（±20）试探再加大，别一上来 ±90。
- 无手臂部件的机型：`getDeviceList()` 里没有 arm 舵机，此时"挥手"可退化为"举头/左右摆头"。

## 4. 做表情（Emotion）

### 最小代码

```java
EmotionController emotion = Robot.globalContext().getSystemService("emotion");

// 播放一次笑脸
emotion.express(new ExpressingOption.Builder(Uri.parse("ubtrobot://emotion/happy"))
        .setLoops(1)
        .build());

// 粘性表情（一直显示直到新表情/dismiss）
emotion.express(new ExpressingOption.Builder(Uri.parse("ubtrobot://emotion/happy"))
        .setSticky(true)
        .build());

// 清空表情（恢复默认脸）
emotion.dismiss();

// 查询当前表情 / 是否在播
Uri current = emotion.getExpressing();
boolean playing = emotion.isExpressing();
```

### ⚠️ 关键：URI 怎么来？

表情 URI 是**设备资源地址，每台设备不同，文档无法替你写死**。四种获取途径：

1. **枚举法（最可靠）**：在设备上遍历常见前缀：
   ```java
   String[] guesses = {
       "ubtrobot://emotion/happy", "ubtrobot://emotion/sad",
       "ubtrobot://emotion/angry", "ubtrobot://emotion/blink",
       "ubtrobot://emotion/smile", "ubtrobot://emotion/love"
   };
   for (String g : guesses) {
       emotion.express(new ExpressingOption.Builder(Uri.parse(g)).build())
           .fail(e -> Log.i("Emo", "无效: " + g));
   }
   ```
2. **查设备资源目录**：`adb shell ls /system/media/ /data/ubtrobot/ /oem/`，找 emotion/motion 相关的 json/gif/mp4 文件。
3. **抓官方 App 日志**：装官方 App 时 `adb logcat | grep -i emotion` 看它请求了什么 URI。
4. **看 Rosa 平台文档残留**：`getExpressing()` 在表情播放中返回的 URI 就是有效格式的活样本。

### 坑

- 无效 URI 不抛异常，**fail 回调里才有错误码**。别只看 done。
- `setSticky(true)` 的表情会挡住后续非粘性表情，记得 `dismiss()`。

## 5. 预置动作表演（Motion：挥手/跳舞/点头的"成品动作"）

> 官方预置了不少编排好的动作（可能就包含"挥手""点头"），**比手搓舵机序列简单**。但同样有 URI 枚举问题。

```java
MotionController motion = Robot.globalContext().getSystemService("motion");

// 播放预置动作
motion.performAction(new PerformingOption.Builder(
        Uri.parse("ubtrobot://motion/wave"))   // 以设备实际 URI 为准
        .setLoops(1)
        .setBpm(1.0f)                          // 倍速：1.0 原速，1.5 快
        .build())
    .done(v -> Log.i("Motion", "动作完成"));

// 停止当前动作
motion.performAction(PerformingOption.EMPTY);
```

## 6. 灯光配合（氛围/反馈）

```java
LightController light = Robot.globalContext().getSystemService("light");

// 动作开始 → 眼睛绿色；动作结束 → 红色
light.turnOn("eye_left", 0xFF00FF00);   // 灯 ID 以 getDeviceList() 为准
light.turnOn("eye_right", 0xFF00FF00);
// ... 做动作 ...
light.changeColor("eye_left", 0xFFFF0000);
light.changeColor("eye_right", 0xFFFF0000);
```

## 7. 综合剧本示例：摸头互动

```java
SensorController sensor = Robot.globalContext().getSystemService("sensor");
ServoController servo   = Robot.globalContext().getSystemService("servo");
EmotionController emo   = Robot.globalContext().getSystemService("emotion");
LightController light   = Robot.globalContext().getSystemService("light");

sensor.registerListener("head_touch", new SensorListener() {
    @Override public void onSensorEvent(String id, SensorEvent e) {
        // 1. 表情：开心
        emo.express(new ExpressingOption.Builder(Uri.parse("ubtrobot://emotion/happy"))
                .setSticky(true).build());
        // 2. 灯光：眼睛变绿
        light.turnOn("eye_left", 0xFF00FF00);
        light.turnOn("eye_right", 0xFF00FF00);
        // 3. 动作：左右摇头表示开心
        servo.rotateSerially(Arrays.asList(
            new RotationOption.Builder("head").setAngle(-20f).setSpeed(80).build(),
            new RotationOption.Builder("head").setAngle(20f).setSpeed(80).build(),
            new RotationOption.Builder("head").setAngle(0f).setSpeed(50).build()
        ));
    }
});
sensor.enable("head_touch");
```

## 8. 已验证参数速查表（本机实测）

| 参数 | 实测值 | 说明 |
|------|--------|------|
| head 舵机角度 | **[-23, 25]** | 安全范围，超出卡机械 |
| 舵机速度 | 15 / 50 / 80 | 均可 |
| 移动速度 | **0.3** | 直线 |
| 转向速度 | **30**（度/秒） | 原地转 |
| duration=0 | 持续运动 | 需显式停止 |
| 负速度 | 后退 / 右转 | 符号约定 |

> 这些值来自本机（小方头）真机测试。**你的设备可能不同**——所有参数先保守起步，逐档上调。
