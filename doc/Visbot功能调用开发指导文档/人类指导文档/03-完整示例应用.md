# 03-完整示例应用：一个面板控制机器人所有动作

> 目标：给你一个**完整可编译运行**的示例应用，一个 Activity 装下所有已验证功能：**扭头、走路、转向、挥手、表情、灯光**。
> 直接可跑的工程在 `tmp/ubt_repo/`（含签名配置，真机验证过）。本篇给出核心代码与结构说明，方便你改造成自己的应用。

## 3. MainActivity.java —— 完整控制面板

```java
package com.you.robotapp;

import android.net.Uri;
import android.os.Bundle;
import android.util.Log;
import android.widget.Button;
import android.widget.EditText;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

import com.ubtrobot.Robot;
import com.ubtrobot.emotion.EmotionController;
import com.ubtrobot.emotion.ExpressingOption;
import com.ubtrobot.light.LightController;
import com.ubtrobot.locomotion.LocomotionController;
import com.ubtrobot.locomotion.LocomotionOption;
import com.ubtrobot.servo.RotationOption;
import com.ubtrobot.servo.ServoController;

import java.util.Arrays;

public class MainActivity extends AppCompatActivity {
    private static final String TAG = "RobotApp";

    private ServoController servo;
    private LocomotionController loco;
    private EmotionController emotion;
    private LightController light;

    private TextView tvStatus;
    private EditText etAngle, etSpeed, etMoveSpeed;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvStatus = findViewById(R.id.tv_status);
        etAngle = findViewById(R.id.et_angle);
        etSpeed = findViewById(R.id.et_speed);
        etMoveSpeed = findViewById(R.id.et_move_speed);

        // 获取四个控制器（服务名固定字符串）
        servo   = Robot.globalContext().getSystemService("servo");
        loco    = Robot.globalContext().getSystemService("locomotion");
        emotion = Robot.globalContext().getSystemService("emotion");
        light   = Robot.globalContext().getSystemService("light");

        bindButtons();
        log("初始化完成，舵机列表: " + servo.getDeviceList());
    }

    private void bindButtons() {
        // —— 扭头 ——
        findViewById(R.id.btn_turn).setOnClickListener(v -> {
            float angle = Float.parseFloat(etAngle.getText().toString());
            int speed = Integer.parseInt(etSpeed.getText().toString());
            servo.rotate(new RotationOption.Builder("head")
                    .setAngle(angle).setSpeed(speed).build())
                .done(x -> log("扭头到 " + angle + "° 完成"))
                .fail(e -> log("扭头失败: code=" + e.getCode()));
        });

        // —— 摇头（串行三段）——
        findViewById(R.id.btn_shake).setOnClickListener(v ->
            servo.rotateSerially(Arrays.asList(
                new RotationOption.Builder("head").setAngle(-20f).setSpeed(80).build(),
                new RotationOption.Builder("head").setAngle(20f).setSpeed(80).build(),
                new RotationOption.Builder("head").setAngle(0f).setSpeed(50).build()))
                .done(x -> log("摇头完成")));

        // —— 归中 ——
        findViewById(R.id.btn_center).setOnClickListener(v ->
            servo.rotate(new RotationOption.Builder("head").setAngle(0f).setSpeed(50).build()));

        // —— 前进 2 秒 ——
        findViewById(R.id.btn_forward).setOnClickListener(v -> {
            float s = Float.parseFloat(etMoveSpeed.getText().toString());
            loco.locomote(new LocomotionOption.Builder()
                    .setMovingSpeed(s).setDuration(2000).build())
                .done(x -> log("前进完成"));
        });

        // —— 后退 2 秒 ——
        findViewById(R.id.btn_backward).setOnClickListener(v -> {
            float s = Float.parseFloat(etMoveSpeed.getText().toString());
            loco.locomote(new LocomotionOption.Builder()
                    .setMovingSpeed(-s).setDuration(2000).build());
        });

        // —— 原地右转 90°（转向速度 30 度/秒）——
        findViewById(R.id.btn_turn_right).setOnClickListener(v ->
            loco.locomote(new LocomotionOption.Builder()
                    .setTurningSpeed(30f).setTurningAngle(90f).build()));

        // —— 原地左转 90° ——
        findViewById(R.id.btn_turn_left).setOnClickListener(v ->
            loco.locomote(new LocomotionOption.Builder()
                    .setTurningSpeed(-30f).setTurningAngle(-90f).build()));

        // —— 停止一切运动 ——
        findViewById(R.id.btn_stop).setOnClickListener(v ->
            loco.locomote(new LocomotionOption.Builder().setEmergency(true).build()));

        // —— 挥手（head 舵机快速摆 3 次，作演示；有手臂部件的机型改用 arm ID）——
        findViewById(R.id.btn_wave).setOnClickListener(v ->
            servo.rotateSerially(Arrays.asList(
                new RotationOption.Builder("head").setAngle(-15f).setSpeed(90).build(),
                new RotationOption.Builder("head").setAngle(15f).setSpeed(90).build(),
                new RotationOption.Builder("head").setAngle(-15f).setSpeed(90).build(),
                new RotationOption.Builder("head").setAngle(15f).setSpeed(90).build(),
                new RotationOption.Builder("head").setAngle(0f).setSpeed(50).build()))
                .done(x -> log("挥手完成")));

        // —— 表情（URI 需按实战指南 §4 在设备上枚举）——
        findViewById(R.id.btn_emoji).setOnClickListener(v ->
            emotion.express(new ExpressingOption.Builder(
                    Uri.parse("ubtrobot://emotion/happy"))
                    .setSticky(true).build())
                .fail(e -> log("表情 URI 无效: " + e.getCode())));
        findViewById(R.id.btn_emoji_off).setOnClickListener(v -> emotion.dismiss());

        // —— 灯光 ——
        findViewById(R.id.btn_light_green).setOnClickListener(v -> {
            light.turnOn("eye_left", 0xFF00FF00);
            light.turnOn("eye_right", 0xFF00FF00);
        });
        findViewById(R.id.btn_light_off).setOnClickListener(v ->
            light.turnOff(Arrays.asList("eye_left", "eye_right")));
    }

    private void log(String msg) {
        Log.i(TAG, msg);
        runOnUiThread(() -> tvStatus.setText(msg + "\n" + tvStatus.getText()));
    }
}
```

## 4. 三个最容易改错的地方

1. **控制器服务名**：`getSystemService("servo")` 的字符串是固定的（servo / locomotion / emotion / light / motion / sensor / power / recharging / part）。拼错不会崩溃，只会返回 null 或调用时异常。
2. **舵机/灯 ID**：`"head"`、`"eye_left"` 是本机实测值。**不同机型必须用 `getDeviceList()` 枚举后替换**。
3. **动作/表情 URI**：`ubtrobot://emotion/happy` 只是格式示例。按实战指南 §4 的 4 种途径在设备上找真实 URI。

## 7. 改造建议：从"遥控面板"到"具身智能"

这个面板只是起点。把「动作调用」接上你自己的大脑（本地 LLM / 语音 / 规则引擎），就是一台可编程的具身设备：

- **规则引擎**：传感器事件 → 动作（摸头 → 开心表情 + 摇头，见实战指南 §7）
- **LLM 驱动**：把 LLM 输出的动作指令映射为 `loco.locomote(...)` / `servo.rotate(...)` / `emotion.express(...)` 调用——`MotionController`/`ServoController` 的接口足够覆盖行走与肢体动作
- **远程控制**：面板逻辑包一层 HTTP/WebSocket，手机当遥控器
- **注意并发**：所有动作调用走同一 Master 服务，多线程调用时自己维护「竞争会话」或串行队列（见 AI 文档 08 §6）
