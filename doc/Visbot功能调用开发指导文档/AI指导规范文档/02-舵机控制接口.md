# 02-舵机控制（Servo）接口

> 用途：控制机器人**单关节舵机**（头部、手臂等）转到指定角度 → 实现**扭头、点头、挥手、抬臂**等动作。
> 接口源码：`tmp/rosa_decompiled/sources/com/ubtrobot/servo/ServoController.java`

## 获取控制器

```java
import com.ubtrobot.Robot;
import com.ubtrobot.servo.ServoController;

Robot.initialize(context.getApplicationContext());
ServoController servo = Robot.globalContext().getSystemService("servo");
```

## 接口全貌

```java
public interface ServoController {
    // ---- 动作 ----
    ProgressivePromise<Void, ServoException, RotationProgress> rotate(RotationOption option);
    ProgressivePromise<Void, ServoException, RotationProgress> rotateSerially(List<RotationOption> options);
    Promise<Void, ServoException> release(String servoId);       // 释放（断电，舵机失去保持力）
    Promise<Void, ServoException> release(List<String> servoIds);

    // ---- 查询 ----
    float getAngle(String servoId);                              // 当前角度
    boolean isRotating(String servoId);                          // 是否在转
    boolean isReleased(String servoId);                          // 是否已释放
    ServoDevice getDevice(String servoId) throws ServoNotFoundException;
    List<ServoDevice> getDeviceList();                           // 全部舵机

    // ---- 监听 ----
    void registerRotationListener(RotationListener listener, Collection<String> servoIds);
    void unregisterRotationListener(RotationListener listener);
}
```

## RotationOption（旋转参数）

```java
RotationOption option = new RotationOption.Builder(servoId)
    .setAngle(45)          // 目标角度，单位度；默认 [-90, 90]（具体范围以 getDevice 返回的硬件范围为准）
    .setAngleAbsolute(true) // true=绝对角度（转到 45°）；false=相对角度（再转 45°）
    .setSpeed(50)          // 速度，[0, 100]
    .setDuration(500)      // 可选：指定耗时（毫秒）；不设则由服务按速度计算
    .build();
```

## 核心用法

### 扭头（Visbot 的头部舵机 ID 为 `"head"`，已在示例工程验证）

```java
// 头转到 +30°（向右看）
servo.rotate(new RotationOption.Builder("head").setAngle(30).setAngleAbsolute(true).setSpeed(50).build());

// 头回到中间 0°
servo.rotate(new RotationOption.Builder("head").setAngle(0).setAngleAbsolute(true).setSpeed(30).build());

// 摇头：相对角度来回摆
servo.rotate(new RotationOption.Builder("head").setAngle(20).setAngleAbsolute(false).setSpeed(80).build());
```

### 挥手（若存在手臂舵机，ID 需先 getDeviceList 查询）

```java
// 枚举所有舵机，确定手臂舵机 ID
for (ServoDevice d : servo.getDeviceList()) {
    Log.i("Servo", "id=" + d.getId() + " range=[" + d.getMinAngle() + "," + d.getMaxAngle() + "]");
}

// 挥手 = 相对角度连续摆动 3 次
String armId = "arm_left"; // 以 getDeviceList 实际返回为准
for (int i = 0; i < 3; i++) {
    servo.rotate(new RotationOption.Builder(armId)
        .setAngle(60).setAngleAbsolute(false).setSpeed(100).build());
    servo.rotate(new RotationOption.Builder(armId)
        .setAngle(-60).setAngleAbsolute(false).setSpeed(100).build());
}
```

### 串行旋转（依次执行多个关节，用于组合姿态）

```java
List<RotationOption> options = Arrays.asList(
    new RotationOption.Builder("head").setAngle(0).setAngleAbsolute(true).setSpeed(50).build(),
    new RotationOption.Builder("arm_left").setAngle(90).setAngleAbsolute(true).setSpeed(80).build(),
    new RotationOption.Builder("arm_right").setAngle(-90).setAngleAbsolute(true).setSpeed(80).build()
);
servo.rotateSerially(options);
```

### 释放 / 停止

```java
// 释放舵机（断电，可被人手随意掰动；常用于"摸头杀"后放松）
servo.release("head");

// 停止正在进行的旋转
servo.release("head");  // ServoController 没有单独 stop；release 即停止
```

### 查询状态

```java
float angle = servo.getAngle("head");          // 当前角度（度）
boolean rotating = servo.isRotating("head");
ServoDevice dev = servo.getDevice("head");
dev.getMinAngle();  // 硬件角度下限
dev.getMaxAngle();  // 硬件角度上限
dev.isRotating();
dev.isReleased();
```

## 监听旋转事件

```java
servo.registerRotationListener(new RotationListener() {
    @Override public void onRotationStarted(String servoId, RotationProgress progress) {}
    @Override public void onRotationOngoing(String servoId, RotationProgress progress) {}
    @Override public void onRotationCompleted(String servoId, RotationProgress progress) {
        Log.i("Servo", servoId + " 旋转完成, 最终角度=" + progress.getAngle());
    }
}, Collections.singletonList("head"));
```

## 异步回调

```java
servo.rotate(new RotationOption.Builder("head").setAngle(45).setSpeed(50).build())
    .done(new DoneCallback<Void>() {
        @Override public void onDone(Void aVoid) { Log.i("S", "到位"); }
    })
    .fail(new FailCallback<ServoException>() {
        @Override public void onFail(ServoException e) {
            Log.e("S", "失败 code=" + e.getCode() + " msg=" + e.getMessage());
        }
    })
    .progress(new ProgressivePromise.ProgressCallback<RotationProgress>() {
        @Override public void onProgress(RotationProgress p) {
            // 进行中：当前角度 p.getAngle()，进度 p.getProgress()
        }
    });
```

## 会话竞争（重要）

舵机可能同时被原厂应用使用。SDK 提供 `SessionAllocator` 申请**竞争会话**，避免两个应用抢同一个舵机：

```java
// 参考 visbot-sdk 的 ServoControllerClient：
SessionAllocator allocator = new SessionAllocator("servo", ServoConstants.COMPETING_ITEM_PREFIX_SERVO);
HashSet<String> ids = new HashSet<>();
ids.add("head");
CompetitionSession session = allocator.allocate(ids);   // 申请成功后独占该舵机
// ... 执行 rotate ...
session.release();                                      // 用完后释放
```

`ServoConstants.COMPETING_ITEM_PREFIX_SERVO` 是竞争项前缀；`SessionAllocator.allocate` 会向 Master 服务发起竞争申请（内部走 IPC）。

## 已在设备验证过的参数（来自示例工程）

| 参数 | 值 | 备注 |
|------|-----|------|
| 舵机 ID | `"head"` | Visbot 头部舵机，实测可转 |
| 角度范围 | [-23, 25]（实测安全范围） | 声明范围更大，实测超界可能碰撞限位 |
| 速度 | 15（慢）/ 50（中）/ 80+（快） | 0-100 |
| 相对角度 | 支持 | `setAngleAbsolute(false)` |

## 底层服务路径（备查）

```
/servo/rotate            旋转
/servo/rotate-serially   串行旋转
/servo/angle             查询角度
/servo/release           释放
/servo/is-rotating       是否在转
/servo/device            单设备
/servo/device-list       设备列表
```

若不用 rosa.jar，可用 `MasterConnection.call(path, json, sessionInfo)` 直接调用（见 08）。
