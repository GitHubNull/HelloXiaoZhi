# 06-灯光（Light）与传感器（Sensor）接口

> 用途：控制机器人 **LED 灯光**（颜色、特效）与**传感器**（触摸/红外/跌落等事件读取）→ 让机器人"眼睛发光""被摸有反应"。
> 接口源码：`tmp/rosa_decompiled/sources/com/ubtrobot/light/LightController.java`、`.../sensor/SensorController.java`

## 获取控制器

```java
import com.ubtrobot.Robot;
import com.ubtrobot.light.LightController;
import com.ubtrobot.sensor.SensorController;

Robot.initialize(context.getApplicationContext());
LightController light = Robot.globalContext().getSystemService("light");
SensorController sensor = Robot.globalContext().getSystemService("sensor");
```

## 一、LightController（灯光）

### 接口全貌

```java
public interface LightController {
    Promise<Void, LightException> turnOn(String lightId, int color);                 // 点亮（ARGB）
    Promise<Void, LightException> turnOn(Map<String, Integer> idToColor);            // 批量点亮
    Promise<Void, LightException> turnOff(String lightId);
    Promise<Void, LightException> turnOff(List<String> lightIds);
    Promise<Void, LightException> changeColor(String lightId, int color);            // 变色
    Promise<Void, LightException> changeColors(Map<String, Integer> idToColor);
    ProgressivePromise<Void, LightException, DisplayProgress> displayEffect(DisplayOption option);   // 灯光特效
    ProgressivePromise<Void, LightException, DisplayProgress> displayEffectSerially(List<DisplayOption> options);
    int getColor(String lightId);
    boolean isTurnedOn(String lightId);
    LightDevice getDevice(String lightId) throws LightNotFoundException;
    List<LightDevice> getDeviceList();                                               // 全部灯
}
```

### 点亮 / 变色 / 关闭

```java
int RED   = 0xFFFF0000;
int GREEN = 0xFF00FF00;
int BLUE  = 0xFF0000FF;

// 点亮眼睛灯（ID 以 getDeviceList 为准）为红色
light.turnOn("eye_left", RED);
light.turnOn("eye_right", RED);

// 批量设置
Map<String, Integer> colors = new HashMap<>();
colors.put("eye_left", GREEN);
colors.put("eye_right", GREEN);
colors.put("chest", BLUE);
light.turnOn(colors);

// 变色
light.changeColor("chest", 0xFFFF00FF);

// 关闭
light.turnOff("eye_left");
light.turnOff(Arrays.asList("eye_left", "eye_right", "chest"));
```

### 灯光特效（呼吸灯/闪烁等）

```java
// DisplayOption 与表情/动作类似：URI 指向特效库 + 循环参数
light.displayEffect(new DisplayOption.Builder("eye_left", effectUri)
        .setLoops(0)          // 0/负数 = 无限循环（sticky 行为）
        .setSticky(true)      // 粘性特效直到新命令
        .build())
    .done(new DoneCallback<Void>() {
        @Override public void onDone(Void v) {}
    });
```

### 查询

```java
for (LightDevice d : light.getDeviceList()) {
    Log.i("Light", "id=" + d.getId());
}
int color = light.getColor("eye_left");       // ARGB
boolean on = light.isTurnedOn("eye_left");
```

## 二、SensorController（传感器）

### 接口全貌

```java
public interface SensorController {
    Promise<Void, SensorException> enable(String sensorId);      // 启用传感器
    Promise<Void, SensorException> disable(String sensorId);     // 停用
    Promise<Void, SensorException> control(ControlOption option); // 高级控制（阈值/采样率等）
    boolean isEnabled(String sensorId);
    SensorDevice getDevice(String sensorId) throws SensorNotFoundException;
    List<SensorDevice> getDeviceList();                          // 全部传感器
    List<SensorDevice> getDeviceList(String type);               // 按类型（touch/infrared/...）
    void registerListener(String sensorId, SensorListener listener);     // 订阅事件
    void unregisterListener(SensorListener listener);
}
```

### 枚举传感器

```java
for (SensorDevice d : sensor.getDeviceList()) {
    Log.i("Sensor", "id=" + d.getId() + " type=" + d.getType());
}
// 或按类型
List<SensorDevice> touches = sensor.getDeviceList("touch");
```

### 启用并订阅触摸事件（"摸头"检测）

```java
String touchId = "head_touch"; // 以 getDeviceList 实际返回为准

sensor.enable(touchId);

sensor.registerListener(touchId, new SensorListener() {
    @Override public void onSensorEvent(String sensorId, SensorEvent event) {
        Log.i("Sensor", sensorId + " 事件: " + event);
        // 例如触摸事件 → 触发机器人动作：
        // motion.performAction(...)
    }
});
```

### 高级控制

```java
sensor.control(new ControlOption.Builder(sensorId)
    // 具体参数（阈值、周期）以 SensorDevice 能力为准
    .build());
```

## 组合示例：被摸头 → 眼睛变绿 + 扭头 + 笑脸

```java
sensor.registerListener("head_touch", new SensorListener() {
    @Override public void onSensorEvent(String id, SensorEvent e) {
        // 1. 眼睛变绿
        light.turnOn("eye_left", 0xFF00FF00);
        light.turnOn("eye_right", 0xFF00FF00);
        // 2. 扭头看向触摸方向
        servo.rotate(new RotationOption.Builder("head").setAngle(20).setSpeed(60).build());
        // 3. 笑脸
        emotion.express(new ExpressingOption.Builder(Uri.parse("ubtrobot://emotion/happy")).build());
    }
});
```
