# 03-运动控制（Locomotion）接口

> 用途：控制机器人**底盘电机** → 实现**前进、后退、左转、右转、原地旋转、按距离行进**。
> 接口源码：`tmp/rosa_decompiled/sources/com/ubtrobot/locomotion/LocomotionController.java`

## 获取控制器

```java
import com.ubtrobot.Robot;
import com.ubtrobot.locomotion.LocomotionController;

Robot.initialize(context.getApplicationContext());
LocomotionController locomotion = Robot.globalContext().getSystemService("locomotion");
```

## 接口全貌

```java
public interface LocomotionController {
    ProgressivePromise<Void, LocomotionException, LocomotionProgress> locomote(LocomotionOption option);
    ProgressivePromise<Void, LocomotionException, LocomotionProgress> locomoteSerially(List<LocomotionOption> options);
    LocomotionDevice getDevice() throws LocomotionDeviceNotFoundException;
    boolean isLocomoting();
}
```

## LocomotionOption（运动参数）

```java
LocomotionOption option = new LocomotionOption.Builder()
    .setMovingSpeed(0.3f)     // 平移速度，[0,1]；正=前进，负=后退
    .setMovingAngle(0)        // 平移方向角（度），0=正前方
    .setMovingDistance(0)     // 平移距离（米？需按设备校准）；0=不限
    .setTurningSpeed(30)      // 转向角速度（度/秒）；正=逆时针（左转），负=顺时针（右转）
    .setTurningAngle(90)      // 转向角度（度）
    .setTurningAxis(LocomotionOption.TURNING_AXIS_CENTER) // 转向轴：CENTER/LEFT/RIGHT
    .setDuration(1000)        // 持续时间（毫秒）；0=持续直到下一条命令
    .setEmergency(false)      // true=紧急停止
    .build();
```

转向轴常量：
```java
LocomotionOption.TURNING_AXIS_CENTER = 0;  // 绕中心原地转
LocomotionOption.TURNING_AXIS_LEFT   = -1; // 绕左轮转
LocomotionOption.TURNING_AXIS_RIGHT  = 1;  // 绕右轮转
```

## 核心用法（已封装于 MotorControllerClient 并经真机验证）

### 前进 / 后退

```java
// 前进：speed 0-1，duration 毫秒（0=一直走直到下条命令）
locomotion.locomote(new LocomotionOption.Builder()
    .setMovingSpeed(0.3f)
    .setMovingAngle(0)
    .setDuration(1000)
    .build());

// 后退：速度为负
locomotion.locomote(new LocomotionOption.Builder()
    .setMovingSpeed(-0.3f)
    .setMovingAngle(0)
    .setDuration(1000)
    .build());
```

### 左转 / 右转 90°

```java
// 左转（逆时针）：turningSpeed 为正
locomotion.locomote(new LocomotionOption.Builder()
    .setTurningSpeed(30)
    .setTurningAngle(90)
    .setTurningAxis(LocomotionOption.TURNING_AXIS_CENTER)
    .build());

// 右转（顺时针）：turningSpeed 为负
locomotion.locomote(new LocomotionOption.Builder()
    .setTurningSpeed(-30)
    .setTurningAngle(90)
    .setTurningAxis(LocomotionOption.TURNING_AXIS_CENTER)
    .build());
```

### 紧急停止

```java
locomotion.locomote(new LocomotionOption.Builder()
    .setMovingSpeed(0)
    .setTurningSpeed(0)
    .setEmergency(true)
    .build());
```

### 组合运动（边走边转 = 弧线）

```java
locomotion.locomote(new LocomotionOption.Builder()
    .setMovingSpeed(0.2f)
    .setTurningSpeed(15)
    .setDuration(2000)
    .build());
```

### 按距离行进

```java
locomotion.locomote(new LocomotionOption.Builder()
    .setMovingSpeed(0.3f)
    .setMovingAngle(0)
    .setMovingDistance(1.0f)   // 走 1 个距离单位后自动停（单位需实测校准）
    .build());
```

### 串行路径（走正方形）

```java
List<LocomotionOption> path = new ArrayList<>();
for (int i = 0; i < 4; i++) {
    path.add(new LocomotionOption.Builder().setMovingSpeed(0.3f).setMovingAngle(0).setMovingDistance(0.5f).build());
    path.add(new LocomotionOption.Builder().setTurningSpeed(40).setTurningAngle(90).build());
}
locomotion.locomoteSerially(path);
```

## 异步回调与进度

```java
locomotion.locomote(option)
    .done(new DoneCallback<Void>() {
        @Override public void onDone(Void v) { Log.i("L", "运动完成"); }
    })
    .fail(new FailCallback<LocomotionException>() {
        @Override public void onFail(LocomotionException e) {
            Log.e("L", "失败 code=" + e.getCode());
        }
    })
    .progress(new ProgressivePromise.ProgressCallback<LocomotionProgress>() {
        @Override public void onProgress(LocomotionProgress p) {
            // 进度：p.getProgress() 0..1
        }
    });
```

## 已封装好的工具类（直接可用）

`tmp/ubt_repo/visbot-sdk/src/main/java/com/visbot/sdk/motor/MotorControllerClient.java` 提供：

```java
MotorControllerClient motor = new MotorControllerClient(context);
motor.moveForward(0.3f, 1000);   // 前进 1 秒
motor.moveBackward(0.3f, 1000);  // 后退 1 秒
motor.turnLeft(30, 90);          // 左转 90°
motor.turnRight(30, 90);         // 右转 90°
motor.stop();                    // 紧急停止
motor.customMove(movingSpeed, movingAngle, turningSpeed, turningAngle, duration);
motor.isConnected();             // LocomotionController 是否获取成功
```

## 已验证参数（真机）

| 参数 | 值 | 备注 |
|------|-----|------|
| movingSpeed | 0.3 | 平稳行走 |
| turningSpeed | 30 度/秒 | 平稳转向 |
| duration=0 | 持续运动 | 必须配合 stop() 停止 |
| 正负号 | speed<0 后退；turningSpeed<0 右转 | 与直觉相反，务必注意 |
