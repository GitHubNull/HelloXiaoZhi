# 07-电源（Power）、回充（Recharging）与部件（Part）接口

> 用途：机器人**休眠/唤醒/关机**、**自动回充**（回桩充电）、**部件热插拔检测**。
> 接口源码：`tmp/rosa_decompiled/sources/com/ubtrobot/{power,recharging,part}/`

## 获取控制器

```java
import com.ubtrobot.Robot;
import com.ubtrobot.power.PowerController;
import com.ubtrobot.recharging.RechargingController;
import com.ubtrobot.part.PartController;

Robot.initialize(context.getApplicationContext());
PowerController power = Robot.globalContext().getSystemService("power");
RechargingController recharging = Robot.globalContext().getSystemService("recharging");
PartController part = Robot.globalContext().getSystemService("part");
```

## 一、PowerController（电源）

```java
public interface PowerController {
    Promise<Void, PowerException> sleep();              // 休眠
    Promise<Void, PowerException> wakeUp();             // 唤醒
    Promise<Void, PowerException> shutdown();           // 关机
    Promise<Void, PowerException> scheduleStartup(int delaySeconds);   // 定时开机
    Promise<Void, PowerException> cancelStartupSchedule();            // 取消定时开机
    BatteryProperties getBatteryProperties();           // 电量/充电状态
    boolean isSleeping();
    void registerBatteryListener(BatteryListener listener);
    void unregisterBatteryListener(BatteryListener listener);
}
```

### 使用示例

```java
// 休眠（省电，需要时 wakeUp）
power.sleep();

// 唤醒
power.wakeUp();

// 关机
power.shutdown();

// 30 分钟后自动开机
power.scheduleStartup(30 * 60);

// 电量
BatteryProperties battery = power.getBatteryProperties();
battery.getLevel();       // 电量百分比
battery.isCharging();     // 是否充电中

// 电量变化监听
power.registerBatteryListener(new BatteryListener() {
    @Override public void onBatteryChanged(BatteryProperties properties) {
        Log.i("Power", "电量 " + properties.getLevel() + "%");
    }
});
```

## 二、RechargingController（自动回充）

```java
public interface RechargingController {
    ProgressivePromise<Void, RechargingException, ConnectingProgress> connectToStation(ConnectingOption option);  // 自动回桩
    ProgressivePromise<Void, RechargingException, DisconnectingProgress> disconnectFromStation();                 // 离桩
    boolean isConnectedToStation();
}
```

### 使用示例

```java
// 自动寻找充电桩并回充（回桩动作 = 自主寻路 + 对准 + 对接，由系统服务完成）
recharging.connectToStation(new ConnectingOption.Builder().build())
    .done(new DoneCallback<Void>() {
        @Override public void onDone(Void v) { Log.i("R", "已回桩充电"); }
    })
    .fail(new FailCallback<RechargingException>() {
        @Override public void onFail(RechargingException e) {
            Log.e("R", "回桩失败 code=" + e.getCode());
        }
    })
    .progress(new ProgressivePromise.ProgressCallback<ConnectingProgress>() {
        @Override public void onProgress(ConnectingProgress p) {
            // 回桩进度（寻找桩→对准→对接）
        }
    });

// 离桩
recharging.disconnectFromStation();

// 是否在桩上
boolean docked = recharging.isConnectedToStation();
```

> 注意：`ConnectingOption` 的具体 Builder 参数（桩 ID 等）以 rosa.jar 反编译源码为准（`com.ubtrobot.recharging.ConnectingOption`）。

## 三、PartController（部件热插拔）

```java
public interface PartController {
    List<Part> getPartList();                        // 全部部件
    List<Part> getPartList(String type);             // 按类型
    Part getPart(String partId) throws PartNotFoundException;
    boolean isPartConnected(String partId);          // 是否已连接
    void registerListener(String partId, PartListener listener);   // 热插拔事件
    void unregisterListener(PartListener listener);
}
```

### 使用示例

```java
// 枚举部件（头、手臂、尾巴等可插拔模块）
for (Part p : part.getPartList()) {
    Log.i("Part", "id=" + p.getId() + " type=" + p.getType() + " connected=" + p.isConnected());
}

// 监听部件插拔
part.registerListener("arm_left", new PartListener() {
    @Override public void onPartConnected(String partId) {
        Log.i("Part", partId + " 已插入");
    }
    @Override public void onPartDisconnected(String partId) {
        Log.i("Part", partId + " 已拔出");
    }
});
```

## 场景示例：低电量自动回充

```java
power.registerBatteryListener(new BatteryListener() {
    @Override public void onBatteryChanged(BatteryProperties p) {
        if (p.getLevel() < 15 && !p.isCharging()) {
            // 低电量 → 停止当前动作 → 回桩充电
            motion.performAction(PerformingOption.EMPTY); // 或直接发起回充
            recharging.connectToStation(new ConnectingOption.Builder().build());
        }
    }
});
```
