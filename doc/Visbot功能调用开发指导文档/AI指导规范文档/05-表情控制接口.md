# 05-表情控制（Emotion）接口

> 用途：在机器人**面部/屏幕**显示表情动画（开心、难过、眨眼、卖萌等）→ 实现"做出某个表情"。
> 接口源码：`tmp/rosa_decompiled/sources/com/ubtrobot/emotion/EmotionController.java`

## 获取控制器

```java
import com.ubtrobot.Robot;
import com.ubtrobot.emotion.EmotionController;
import com.ubtrobot.emotion.ExpressingOption;

Robot.initialize(context.getApplicationContext());
EmotionController emotion = Robot.globalContext().getSystemService("emotion");
```

## 接口全貌

```java
public interface EmotionController {
    ProgressivePromise<Void, EmotionException, ExpressingProgress> express(ExpressingOption option);
    ProgressivePromise<Void, EmotionException, ExpressingProgress> expressSerially(List<ExpressingOption> options);
    Promise<Void, EmotionException> dismiss();   // 取消当前表情（回到默认脸）
    Uri getExpressing();                         // 当前正在表达的表情 URI
    boolean isExpressing();                      // 是否正在表达
}
```

## ExpressingOption（表情参数）

```java
ExpressingOption option = new ExpressingOption.Builder(emotionUri)
    .setLoops(1)            // 循环次数
    .setSticky(false)       // true=粘性表情（持续显示直到 dismiss 或被新表情替换）
    .setExtension(null)     // 可选 JsonObjectString 扩展参数
    .build();
```

## 核心用法

### 显示表情

```java
// 表情 URI 需以设备表情库为准（获取方式见下）
Uri happyUri = Uri.parse("ubtrobot://emotion/happy");

emotion.express(new ExpressingOption.Builder(happyUri)
        .setLoops(3)          // 播放 3 次
        .build())
    .done(new DoneCallback<Void>() {
        @Override public void onDone(Void v) { Log.i("E", "表情播放完"); }
    })
    .fail(new FailCallback<EmotionException>() {
        @Override public void onFail(EmotionException e) {
            Log.e("E", "失败 code=" + e.getCode());
        }
    });
```

### 粘性表情（一直显示直到取消）

```java
// 摆一张"难过脸"直到有新表情或 dismiss
emotion.express(new ExpressingOption.Builder(Uri.parse("ubtrobot://emotion/sad"))
    .setSticky(true)
    .build());
```

### 取消表情

```java
emotion.dismiss();  // 回到默认脸
```

### 串行表情（表情序列 = 一段情绪表演）

```java
List<ExpressingOption> show = Arrays.asList(
    new ExpressingOption.Builder(Uri.parse("ubtrobot://emotion/surprised")).build(),
    new ExpressingOption.Builder(Uri.parse("ubtrobot://emotion/happy")).setLoops(2).build(),
    new ExpressingOption.Builder(Uri.parse("ubtrobot://emotion/blink")).build()
);
emotion.expressSerially(show);
```

### 查询

```java
boolean expressing = emotion.isExpressing();
Uri current = emotion.getExpressing();  // 当前表情 URI；null/EMPTY=无表情
```

## 表情 URI 从哪来

与动作 URI 同理（见 04），获取途径：

1. **设备表情库**：
   ```bash
   adb shell find /system /data /vendor -type d -iname "*emotion*" 2>/dev/null
   adb shell find /system /data /vendor -type f \( -iname "*.png" -o -iname "*.gif" -o -iname "*.json" \) 2>/dev/null | grep -iE "emotion|expression|face" | head -50
   ```

2. **通过 Master 服务查询**（参照 servo 的 `/servo/device-list` 模式）：
   ```java
   master.call("/emotion/emotion-list", new HashMap<>());
   master.call("/emotion/emotions", new HashMap<>());
   ```

3. **抓原厂应用调用**：
   ```bash
   adb logcat | Select-String -Pattern "emotion|express"
   ```
